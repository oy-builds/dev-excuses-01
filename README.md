# The Deploy Did It

A make.fun entry for "Make the AI Judge Laugh: Developer Excuses": one funny
single-line excuse a developer gives when code breaks in production.

`main.ts` (Node 22, standard library only) writes the excuse to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> I didn't break prod — the deploy did. I just wrote the code, reviewed it, approved it, and merged it.

Run it with `node main.ts`.
